# Creative Scenarios

## Instructions
1. Use the 8-scenario framework documented in `SCENARIOS/README.md`.
2. For each scenario, produce a concept grounded in `CONTEXT/CONTEXT_BRIEF.md` + `RESEARCH/INSIGHTS.md`.
3. Keep brand guardrails as hard constraints; no invented facts/claims.
4. Feed selected scenarios into `brief-writer` → `canva-production-pipeline`.

## Examples
- "Develop launch scenarios for the new product" → 8 scenario concepts with key message + channel fit.

## Performance Notes
- Diverge first (breadth of concepts), then converge to the strongest 2-3.

## Troubleshooting
- Thin research → mark insight gaps `araştırılacak`, still draft concept skeletons.
