# SCENARIOS — 8-Scenario Framework

Türkçe not: Yaratıcı konseptleri sekiz senaryo çerçevesinde geliştir. Her senaryo
`CONTEXT/CONTEXT_BRIEF.md` + `RESEARCH/INSIGHTS.md` üzerine oturur. Marka kuralları
sert kısıttır; **uydurma iddia yok**.

Use with the `creative-scenarios` skill. Each scenario produces a concept with a single
key message and channel fit, then feeds `brief-writer` → `canva-production-pipeline`.

## The 8 scenarios
1. **Launch / Announcement** — introduce a new product/offer.
2. **Awareness / Brand story** — who we are, why we matter.
3. **Consideration / Education** — explain features, how it works.
4. **Promotion / Offer** — time-bound deal or incentive.
5. **Social proof / Testimonial** — real customers/results (must be verified — no fabrication).
6. **Seasonal / Moment** — tie to a calendar/cultural moment (verify dates).
7. **Retention / Loyalty** — re-engage existing customers.
8. **Performance / Direct response** — conversion-focused, clear CTA.
